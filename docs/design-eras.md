# ร่างออกแบบ: ชั้นยุค (PLAN ข้อ 4)

ร่าง 2026-11-05 · ใช้กับ PLAN ข้อ 4 (แนวการเล่นแต่ละยุค + หลอดยุค) และเป็นฐานของ 4c (ขยายเรื่องถึง 2484) · ตัวเลขทุกตัวเป็นของเกม

## 1. เป้าหมาย
- **ผู้เล่น:** รุ่น 1 กับรุ่น 5 เจอเกมที่ต่างกันจริง ไม่ใช่วงจรเดียวกันกับข่าวคนละข่าว
- **โครงสร้าง:** "อะไรมีอยู่ในปีไหน" เป็นข้อมูลที่อ่านได้ที่เดียว ไม่ฝังอยู่ในโค้ด — พอขยายถึง 2484 (เลิกทาส มีนามสกุล ศักดินาหมดความหมาย) จะแก้ที่ข้อมูล ไม่ต้องไล่แก้ทุกระบบ

## 3. ข้อเสนอ

### ก. ยุคเป็นข้อมูล (`rules.json` › `eras` — เดิมเสนอไฟล์ใหม่ ย้ายมาไว้ใน rules.json ที่ทุกตัวโหลดอยู่แล้ว)
```json
{ "eras": [
  { "id": "late_ayutthaya", "name": "ปลายกรุงศรีอยุธยา", "from": 2288, "to": 2308, "capital": "ayutthaya", "theme": "…", "loreRefs": [] },
  …
] }
```
- `ERAS` ใน `views.ts` อ่านจากไฟล์นี้แทน; หลอดยุคได้ข้อมูลเดียวกัน
- `capital` ใช้กับ 4b (แผนที่) — ยังไม่มีผลอื่นในรอบนี้

### ข. เงื่อนไขปีและยุค
- `Condition` เพิ่ม `{ type: 'year', min?, max? }` และ `{ type: 'era', in: [...] }` ใช้ได้ทั้ง `trigger.requires` และ `conditions` ของตัวเลือก
- ตัวตรวจ: event ที่มีเงื่อนไขปีต้องมีช่วงซ้อนกับช่วงเกม; `era.in` ต้องเป็น id ที่มีอยู่

### ค. ตารางสถาบัน/กฎหมาย (ช่องเสียบไว้ก่อน ยังไม่เปลี่ยนพฤติกรรม)
```json
"institutions": {
  "slavery":     { "until": null, "loreRefs": [] },
  "corvee":      { "until": null },
  "sakdinaIncome": { "until": null },
  "surnames":    { "from": 2456 },
  "inoculation": { "from": 2382 }
}
```
- โค้ดถาม `institutionActive(ctx, 'slavery')` แทนการถือว่าเป็นจริงเสมอ — รอบนี้ทุกข้อยังเปิดตลอด 2288–2400 ผลเล่นจึงไม่เปลี่ยน
- ย้าย `balance.mortality.inoculationFrom` มาที่นี่ (ข้อเดียวที่มีปีอยู่แล้ว)
- 4c จะเติมปีสิ้นสุดเอง (เช่น เลิกทาส) พร้อม lore

### ง. lint คำผิดยุคตามช่วงของ event
- ข้อความของ event ที่มีเงื่อนไขปี ตรวจกับ `validFrom` ตามช่วงนั้น (event หลัง 2456 ใช้คำว่านามสกุลได้)

### จ. เนื้อหาเฉพาะยุค (ส่วนที่ผู้เล่นรู้สึก)
ระบบข้อ ก–ง ไม่ทำให้ผู้เล่นรู้สึกอะไรเอง ต้องมี event ที่เกิดได้เฉพาะบางยุคและเล่นต่างกันจริง ข้อเสนอธีม (ต้องหา lore ก่อนเขียน):

| ยุค | ธีมที่เสนอ | มีอะไรแล้ว |
|---|---|---|
| ปลายกรุงศรี 2288–2308 | ความสงบ ราชการ การค้ากับต่างชาติ | ราชการ งานบุญ |
| ศึกพม่า/เสียกรุง 2308–2313 | เอาตัวรอด | ศึก 2308–2310 ครบ |
| ธนบุรี 2313–2325 | ฟื้นตัว ตั้งตัวใหม่ ข้าวยาก | ความโปรดปรานถ้าตามพระยาตาก |
| ร.1 2325–2352 | สร้างกรุงใหม่ ย้ายเรือน ศึกเก้าทัพ | ศึกเก้าทัพ/ท่าดินแดง |
| ร.2–3 2352–2394 | การค้าสำเภา เงินทอง โรคระบาด | ไข้ป่วง ปลูกฝี |
| ร.4 2394–2400 | ฝรั่งเข้ามา การเปลี่ยนแปลงใหม่ | — |

รอบนี้เสนอ **event เฉพาะยุค 1–2 ตัวต่อยุคที่ยังว่าง** (ธนบุรี, ร.1 ย้ายเรือนไปกรุงใหม่, ร.2–3 การค้า, ร.4) เป็นต้นแบบให้ 4c ต่อ

### ฉ. "เกมจบเร็วเกินไป"
ข้อนี้ยังรอคำตอบว่าผู้เล่นหมายถึงอะไร; เนื้อหาเฉพาะยุค (ข้อ จ.) แก้ทาง "แต่ละปีมีเรื่องให้ตัดสินใจมากขึ้น" ส่วนลดความเร็วสูงสุด (`SPEED_DAYS_PER_SEC` สูงสุด 180 วัน/วินาที) เป็นงานเล็กแยกทำได้

## 4. ลำดับงาน
| ขั้น | งาน | เสร็จเมื่อ |
|---|---|---|
| 1 | `eras.json` + `ERAS` อ่านจากไฟล์ | หลอดยุคแสดงเหมือนเดิม, `sim:check` ผ่าน |
| 2 | `Condition` ปี/ยุค + ตัวตรวจ | มีเทสต์ว่า event ที่มีเงื่อนไขปีออกเฉพาะช่วงนั้น |
| 3 | ตารางสถาบัน + ย้าย `inoculationFrom` + `institutionActive` ใน `servants.ts`/`career.ts` | ผลเล่นไม่เปลี่ยน (สมดุลเท่าเดิม) |
| 4 | lint คำผิดยุคตามช่วงของ event | `lore:check` ผ่าน |
| 5 | event เฉพาะยุค (ข้อ จ.) ทีละยุค พร้อม lore | ลองเล่นในเบราว์เซอร์เห็น event ในยุคนั้นเท่านั้น |

## 5. ผู้ใช้ตัดสินแล้ว (2026-11-05)
1. ขอบเขต: **โครงสร้าง (ขั้น 1–4) + event เฉพาะยุค (ขั้น 5)**
2. ตารางสถาบัน: **ช่องเสียบไว้ก่อน ผลเล่นไม่เปลี่ยน** — ย้ายแค่ `inoculationFrom` เข้ามา
3. event เฉพาะยุครอบแรก: **ธนบุรี 2313–2325** (ยุคอื่นรอบหน้า)
4. ความเร็วสูงสุดของนาฬิกา: **คงเดิม** ดูหลังผู้เล่นลองเนื้อหาเฉพาะยุค

## 6. ผลหลังทำ (2026-11-05)
- **ข้อมูล:** `rules.json` › `eras` (6 ยุค) และ `institutions` (ทาส เกณฑ์ไพร่ รายได้ตามศักดินา นามสกุล ปลูกฝี) — `ERAS` ใน `views.ts` ลบแล้ว หลอดยุคอ่านจากข้อมูล
- **โค้ด:** `src/systems/eras.ts` (`eraAt`, `institutionActive`); `Condition` ชนิด `year`/`era`; ทาส/ไพร่ใน `servantsYearTick` และรายได้ตามศักดินาใน `careerYearTick` ถาม `institutionActive` (ยังเปิดตลอด ผลเล่นเท่าเดิม); `balance.mortality.inoculationFrom` ย้ายไปเป็น `institutions.inoculation.from`
- **lint:** คำผิดยุคตรวจกับช่วงปีของ event (เงื่อนไข `year` ใน trigger หรือปีที่นัดใน `historyEvents`); `lore:check` ตรวจ `loreRefs` ของยุค สถาบัน และ event
- **shock กลางปี:** `HistoricalEvent.day` — ผลัดแผ่นดิน 2325 ลงวันที่ 120 (ตัวเลขของเกม) ให้ event เลือกข้างวันที่ 90 มาก่อน; คนตายจาก shock กลางปีได้งานศพ/มรดก/ผู้สืบเหมือนตอน 1 ม.ค. (`settleDeathsToday` ใน `world.ts` — ตอนทำพบว่าไม่งั้นเรือนค้างหัวเรือนที่ตายแล้ว)
- **event ยุคธนบุรี:**
  - `thonburi.rice_dole` ข้าวแจกที่ธนบุรี (นัดวันที่ 120 ของปี 2311 ตาม lore จ.ศ. 1130; เดิมเป็น event สุ่ม 2311–2312 แต่ลองเล่นในเบราว์เซอร์ 2 ปีไม่ขึ้นเลย จึงเปลี่ยนเป็นนัดวัน — ยังมีเงื่อนไข `year` อยู่, lore `event.famine_2310_2313`): ต่อแถวรับข้าวแจก (เสียหน้า) / ซื้อข้าวแพง 4 ตำลึง / อดมื้อกินมื้อ (เสี่ยงป่วย 30%)
  - `thonburi.succession_side` ขุนนางแตกเป็นสองฝ่าย (2325 เฉพาะผู้มีตำแหน่ง, lore `event.thonburi_succession_2325`): เข้าฝ่ายพระยาสรรค์ (ตระกูลถูกนับเป็นฝ่ายนั้น) / ฝ่ายพระยาสุริยอภัย (ความโปรดปราน เสี่ยงบาดเจ็บ 25%) / ปิดประตูเรือน
  - **เปลี่ยนการกวาดล้าง 2325:** จากเดิม "ทุกตระกูลที่รับราชการสมัยธนบุรี 30%" เป็น "ตระกูลฝ่ายพระยาสรรค์ 70%" ตาม `gameMapping` ใน lore — ผู้ที่ไม่เลือกข้างหรือไม่มีตำแหน่งไม่ถูกกวาดล้างแล้ว (ป้าย `faction:taksin_loyalist` ยังติดอยู่แต่ไม่มีผล)
  - ภาพ: ใช้ภาพที่มีอยู่ (`scene.war_hunger`, `scene.audience_hall`)
- **ทดสอบ:** `sim:check` [5h4] (ยุคต่อกัน เงื่อนไขปี/ยุค สถาบันยังเปิด ข้าวแจกเฉพาะ 2311–2312 เลือกข้างก่อน shock และกวาดล้างราว 70% ข้อความครบ)
- **ยังไม่ได้:** ลองเล่นในเบราว์เซอร์ถึง 2311/2325, event ยุคอื่น (ร.1 ร.2–3 ร.4)
