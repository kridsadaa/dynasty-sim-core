# ร่างออกแบบ: เมือง สายน้ำ การเดินทาง และโรคระบาดที่ลามตามเส้นทาง

ร่าง 2026-11-05 · อยู่ใน PLAN ข้อ 4b (ต่อจากข้อ 4) · ตัวเลขทุกตัวในเอกสารนี้เป็นของเกม เว้นแต่บอกที่มาใน lore

## 1. ผู้เล่นควรรู้สึกอะไร

- การเดินทางเป็นการตัดสินใจ ไม่ใช่ข้อความ: "จะไปเยี่ยมพ่อที่บางกอก ทางเรือผ่านปากน้ำเร็วแต่ข่าวว่าไข้ป่วงลงที่นั่น หรืออ้อมทางบกสามวันผ่านป่าที่มีโจร"
- โรคระบาดมาจากที่ไหนสักแห่งแล้วใกล้เข้ามา ไม่ใช่ลงทั้งแผ่นดินพร้อมกันในวันเดียว — ข่าวที่ได้ยินก่อนมีความหมาย
- ที่อยู่มีผล: เรือนริมแม่น้ำใหญ่ค้าขายง่าย แต่รับโรครับข่าวก่อน

## 3. โมเดล

### 3.1 แผนที่: กราฟเมือง–เส้นทาง
- **จุด (place):** `id`, ชื่อ, ชนิด (เมืองหลวง หัวเมือง ตำบลริมน้ำ ด่าน), ประชากรเป็นขั้น 1–5 (ตัวเลขของเกม — หลักฐานรายเมืองแทบไม่มี), `loreRefs`, ปีที่มีอยู่ (`from`/`to`)
- **เส้นทาง (route):** จุด A–B, ชนิด (แม่น้ำ คลอง ทะเล ทางบก), ระยะเป็นวันแยกฤดู (`days: { flood, dry }` — ทางน้ำเร็วตอนน้ำมาก ทางบกช้าตอนน้ำท่วม; บางคลองปิดหน้าแล้ง), ความเสี่ยงประจำเส้น (โจร จมน้ำ) ใช้ `kill.chance`/`risk` ที่มีอยู่
- **เมืองหลวงย้าย:** อยุธยา (ถึง 2310) → ธนบุรี (2310–2325) → บางกอก/กรุงเทพฯ (2325 ขึ้นไป) — จุดเดียวกันใช้ได้หลายยุคด้วย `from`/`to` ไม่ต้องทำแผนที่สองชุด
- **ขนาดรอบแรก:** 10–15 จุดตามลำน้ำเจ้าพระยาตั้งแต่อยุธยาถึงปากน้ำ + ทางแยกตะวันตก (ทางที่ไข้ป่วง 2363 มา) — เล็กพอค้น lore ได้ครบ

### 3.2 เลือกเส้นทาง
- Dijkstra บนกราฟ (จุดไม่ถึงร้อย คิดทุกครั้งได้สบาย) ต้นทุน = วัน + น้ำหนักความเสี่ยง × (โจร + จมน้ำ + โรคที่จุดผ่าน)
- ผู้เล่นไม่ต้องเห็นตัวเลข: ระบบหา 2–3 เส้นที่ต่างกันจริง (เร็วสุด / ปลอดภัยสุด / เลี่ยงโรค) แล้วเสนอเป็นตัวเลือกใน event พร้อมคำใบ้แบบที่มีอยู่ ("ราว 4 วัน · ผ่านปากน้ำที่มีไข้ป่วง · อาจติดโรค (ราว 30%)")

### 3.3 โรคระบาด: SIR หลายพื้นที่ (metapopulation SIR)
- แต่ละจุดเก็บแค่สัดส่วน ป่วย/หายแล้ว (ไม่จำลองรายคน) — รันวันละครั้งใน worker เบามาก
- ลามระหว่างจุดตามเส้นทางแบบ gravity: แรงลาม ∝ (ประชากร A × ประชากร B) / ระยะวัน; เส้นทางน้ำแรงกว่าทางบก (คนเดินทางมากกว่า)
- **เริ่มจากประวัติศาสตร์:** ไข้ป่วง 2363 ปล่อยที่ "หัวเมืองฝ่ายตะวันตก" เดือน 7 แล้วปรับค่าให้ถึงกรุงในราว 15 วันตาม lore; 2392 ยังไม่มีเส้นทางใน lore (ต้องค้น)
- **ต่อกับความตายที่มีอยู่:** โอกาสตายของคนในเรือน = ความเข้มของโรคที่จุดของเรือนสะสมตลอดช่วงระบาด × ตัวคูณการเตรียมตัวเดิม (`flee`/`home`/`merit`) — ปรับเทียบให้ยอดตายรวมในกรุงใกล้ `deathRisk` 0.2 เดิม
- "หนีออกจากกรุง" (ตัวเลือก `flee` เดิม) กลายเป็นการย้ายไปจุดที่โรคยังไม่ถึงจริงๆ — ได้ผลเฉพาะเมื่อหนีถูกทาง

### 3.4 ความหนาแน่นประชากร
- รอบแรกใช้แค่ในแรงลามของโรค
- ภายหลัง (ระบบอาชีพ/ถิ่นกำเนิด): คนนอกตระกูลที่สุ่มขึ้นมามีบ้านเกิดตามสัดส่วนประชากร, เมืองใหญ่มีคู่ครอง/งานให้เลือกมากกว่า

## 4. ผู้เล่นเดินทางเมื่อไร (รอบแรก)
ตอนนี้ผู้เล่นแทบไม่มีเหตุให้เดินทาง จึงต้องมีจุดที่บังคับให้คิดเรื่องเส้นทาง:
1. **หนีโรค:** `plague.news` ตัวเลือก "หนี" ให้เลือกว่าจะไปไหนและทางไหน
2. **เยี่ยม/ดูแลญาติต่างเมือง:** พ่อแม่ป่วยหนัก (`family.parent_illness` มีอยู่แล้ว) เมื่อพ่อแม่อยู่ต่างจุด — เกิดได้เมื่อลูกแต่งออกไปอยู่บ้านฝ่ายหญิงต่างตำบล (lore `kinship.residence_mixed_census`)
3. **ราชการ:** ถูกส่งไปหัวเมือง — ยังไม่มีในเกม (ไม่มี event ราชการที่ส่งไปต่างเมือง) ต้องทำใหม่ จึงไว้หลังสองข้อแรก

การเดินทางรอบแรก **คิดผลทันทีตอนเลือก** (ทอยความเสี่ยงของเส้นทางครั้งเดียว + เวลาที่หายไปจากเรือนเป็นจำนวนวัน) ไม่ต้องทำระบบ "ตัวละครอยู่ระหว่างทาง" ซึ่งต้องแก้ worker และ UI มาก

## 6. ความเสี่ยง
- **ระบบใหญ่ที่ผู้เล่นมองไม่เห็น:** ถ้าเดินทางไม่บ่อย โรคลามตามแผนที่ก็แค่เปลี่ยนจาก "ตายทั้งแผ่นดิน" เป็น "ตายในกรุง" — จึงทำขั้น 3 ต่อจากขั้น 2 ทันที ไม่ทิ้งไว้
- **lore ไม่พอ:** ถ้าค้นขั้น 0 แล้วได้น้อย ให้ลดเหลือ 6–8 จุดที่มีหลักฐาน ไม่แต่งเมืองขึ้นเอง
- **สมดุล:** โรคที่ไม่ลงทุกคนเท่ากันอาจทำให้ตระกูลสิ้นสายมากขึ้น/น้อยลง — ประตู `sim:policy` (สิ้นสาย ≤ 25%) ต้องผ่าน
- **เซฟเก่า:** ต้อง migrate ให้ทุกเรือนมี `placeId`

## 7. ผู้ใช้ตัดสินแล้ว (2026-11-05)
1. ขอบเขตแผนที่รอบแรก: **ลำน้ำเจ้าพระยาอยุธยา–ปากน้ำ + ทางตะวันตก (10–15 จุด)**
2. การเดินทางรอบแรก: **คิดผลทันทีตอนเลือก** (ทอยความเสี่ยงครั้งเดียว + นับวันที่หายไปจากเรือน) ไม่ทำตัวละครอยู่ระหว่างทาง
3. ไข้ป่วง 2363: **ลามตามแผนที่** แทน shock ทั้งแผ่นดิน ปรับเทียบยอดตายในกรุงให้ใกล้ของเดิม; 2392 ใช้แบบเดิมจนกว่าจะมี lore เส้นทาง
4. แผนที่บนหน้าจอ: **ยังไม่ทำรอบแรก** ตัวเลือกเส้นทางอยู่ใน event และคำใบ้
5. ลำดับ: **เข้า PLAN ต่อจากข้อ 4** (แนวการเล่นแต่ละยุค + หลอดยุค) — ค้น lore ขั้น 0 ทำคู่ขนานได้ระหว่างรอ
