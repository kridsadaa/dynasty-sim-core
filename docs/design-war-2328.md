## 1. ตอนนี้เกมทำอะไรกับศึกนี้

- `rules.json` › `history:nine_armies` ปี 2328: ทุกคนวัย 18–50 ทอยตาย (ชาย 8% หญิง 1%) + เสียทรัพย์ 0–5% และ `history:tha_din_daeng` ปี 2329 (ชาย 4%) — **ผู้เล่นไม่ได้เลือกอะไรเลย** แค่อ่านข่าว
- ผู้เล่นรุ่นแรก (เกิด 2281) อายุ 47 ตอนนี้ — มักเป็นรุ่นที่ 1 ปลายชีวิตหรือรุ่นที่ 2 อายุ 20–30 จึงเป็นศึกแรกที่ผู้สืบเจอ

## 2. หลักฐาน (lore ที่มี)

`event.nine_armies_2328` (verified, พงศาวดาร ร.1 ฉบับทิพากรวงศ์ บทที่ 31–33) และ `event.tha_din_daeng_2329` (บทที่ 44):
- พม่ายกมาหลายทางพร้อมกัน รวม 103,000; ไทยจัดทัพกรมพระราชวังบวรฯ ทางกาญจนบุรี 30,000 ทัพหลวงหนุน 20,000 ฯลฯ
- **วินัยโหด:** นายทัพกองโจร 3 คนถูกตัดศีรษะเพราะหลีกหนีข้าศึก; ประกาศว่าผู้ถอยหนีจะ "เอาตัวลงครกโขลก"
- **ทางบ้าน:** ปีเดียวกันน้ำมาก ข้าวแพงถึงเกวียนละชั่ง หลวงแจกข้าวฉาง
- **ข่าวถึงกรุง:** บทที่ 32 — "วันอาทิตย์ เดือน ๑๒ แรม ๙ ค่ำ ปีมะเส็ง สัปตศก จุลศักราช ๑๑๔๗" (เชิงอรรถเทียบราว 20 พ.ย. 1785) — **ยังไม่ได้ลง lore** (อ่านเมื่อ 2026-11-04 เพื่อร่างนี้)
- ปีถัดมา ท่าดินแดง: เกณฑ์ซ้ำ ศึกสั้นและชนะ

**ข้อที่ไม่มีหลักฐาน (จะเป็น `invented`):** ยอดตายฝ่ายไทย, วิธีเกณฑ์ไพร่ทีละเรือนในกรุง, การจ้างคนแทน, บทลงโทษคนหลบเกณฑ์ (ศึก 2308 ใช้ตัวเลขเกมเช่นกัน)

## 5. กลไกที่ใช้ซ้ำ / ต้องเพิ่ม

ใช้ซ้ำได้เลย:
- ตารางนัดหมาย `rules.json` › `historyEvents` (`src/systems/historyEvents.ts`) — ใส่ปี/วัน/อายุขั้นต่ำ
- ตัวเลือกเสี่ยง `risk` + `factors` (skill/personality) + `hintKey` บอกความเสี่ยงก่อนเลือก
- effect ที่มี: `favor`, `prestige`, `merit`, `wealth`, `wound`, `skill`, `kill` (`allowKin`), `stress`
- badge ยุค (`eraConditions`) จาก `history` + `lasts`

ต้องเพิ่ม:
1. **state ของศึกครั้งนี้** — `meta.war` ปัจจุบันผูกกับศึก 2308 (`prep`, `stance`, `dir`, `party`, `taksin`) เสนอเพิ่มฟิลด์แยก `meta.campaigns?: Record<string, { soldier?: CharacterId; conduct?: 'front'|'orders'|'fallback'; outcome?: ... }>` คีย์ด้วยชื่อศึก (`nine_armies`, `tha_din_daeng`) — ใช้ซ้ำกับศึกต่อๆ ไป (ถลาง อนุวงศ์ อานาม) โดยไม่ต้องเพิ่มฟิลด์ทุกครั้ง; เซฟเก่าไม่มีฟิลด์ = ยังไม่เริ่ม
2. **ส่งคนอื่นไปแทน** — ตัวเลือกที่เลือกคน (คล้าย `war.decide_leave` ที่เลือกพาใคร) แล้วความเสี่ยงของ `front` ใช้สเตตัสของคนนั้น; ถ้าคนที่ไปไม่ใช่ผู้เล่น ผลคำนวณอัตโนมัติจากสเตตัส (ไม่มี event `front` ให้ผู้เล่นเลือก)
3. **ความดีความชอบ → ยศ** — flag `merit-in-war` ที่ทำให้การทอยเลื่อนยศรอบถัดไปได้โบนัส (ผูก PLAN ข้อ 12 เพดานยศ)
4. **แทน shock เดิมเฉพาะคนในเรือนผู้เล่น** — คนในเรือนตายได้ผ่านตัวเลือกเท่านั้น (หลักข้อ 1 ของศึก 2308); คนนอกเรือน (NPC) ยังใช้ shock แบบเดิมเพื่อให้โลกมีคนตายจากศึก

## 6. สมดุล

- เป้า (ร่าง): ชายในเรือนที่ไปทัพเองแบบ "ทำตามคำสั่ง" ตายราว 5–10%; "ยืนแนวหน้า" 15–25% แต่ได้รางวัลที่ทำให้อยากเสี่ยง (ตัดสิน 2308 ข้อ 1); "ถอย" ตายต่ำแต่มีโอกาสโดนโทษ
- ต้องเพิ่มนโยบายใน `sim:policy` สำหรับศึกนี้ (ไปเอง/ส่งแทน/จ่าย/หลบ × แนวหน้า/ตามคำสั่ง/ถอย) และวัดว่าไม่มีกลยุทธ์ครอบงำ
- `balanceCheck`: ตายก่อน 30 และสิ้นสายต้องไม่แย่ลง (ศึกนี้อยู่หลังรุ่นแรก จึงกระทบสิ้นสายมากกว่า)
- ตัวเลขทั้งหมดเป็นของเกม ติดป้าย `invented` ใน lore (`event.nine_armies_options` แบบเดียวกับ `event.plague_response_options`)

## 8. ข้อตัดสิน

ตัดสินแล้ว (ผู้ใช้ 2026-11-04):
1. **ปีที่เหลื่อม → ย้ายตามวันจริง + ตรวจทุกศึก:** เก้าทัพ (ข่าว พ.ย. 2328 → แตก ก.พ. 2329) และท่าดินแดง (ก.พ. 2330) ย้ายตามวันในหัวข้อ 3; รายการ `history` อื่นตรวจแบบเดียวกันเป็นงานแยก
2. **ส่งคนอื่นไปแทน → ได้:** ลูกชาย/น้องชาย/บ่าวชายวัย 18–50 ในเรือน (ขั้น 3)
3. **ความตายของคนในเรือนผู้เล่น → ตายจากตัวเลือกเสี่ยงเท่านั้น:** ถอด shock สุ่มสำหรับคนในเรือนผู้เล่น; NPC นอกเรือนยังใช้ shock เดิม
5. **โทษคนถอย/หลบ → ถอด/ปรับ/เฆี่ยน ไม่ถึงตาย:** ประหารนายทัพเป็นเรื่องเล่าในข้อความ (ตามพงศาวดาร) แต่ตัวละครผู้เล่นโดนแค่เสียตำแหน่ง เงิน ความโปรดปราน และบาดแผลจากการเฆี่ยน

ยังรอ (ใช้ข้อเสนอนี้ถ้าผู้ใช้ไม่ว่าอะไร):
4. **รางวัล:** เสนอ "โบนัสเลื่อนยศรอบหน้า" (ไม่ข้ามขั้นทันที — ไม่ทำให้สมดุลราชการเพี้ยน) ยกเว้นยืนแนวหน้าแล้วรอดได้เลื่อนทันทีหนึ่งขั้น
6. **ขอบเขตรอบแรก:** เสนอทำเก้าทัพก่อน (ขั้น 1–5) แล้วท่าดินแดงตาม (ขั้น 6) เพราะใช้แม่แบบเดียวกัน
