## ธีมของยุคหนึ่งๆ (ทำเมื่อมีโครงยุคแล้ว)
เหตุผลที่พัก: เป็นเนื้อหาเฉพาะยุค ควรทำหลังกำหนดธีมการเล่นแต่ละยุคใน PLAN ข้อ 4

- [ ] **ชาวต่างชาติยังไม่มีในเกม** — กติกาภาษาพร้อมแล้ว (`vocab.foreign_languages_by_group`: ยุโรปและล่ามคาทอลิกใช้โปรตุเกส, พ่อค้ามุสลิม/มลายูใช้มลายู, ชาวจีนใช้ภาษาจีนของตน) มีคำโปรตุเกสที่ลา ลูแบร์บันทึก (`vocab.portuguese_terms_1680s`) และ `formatPortuguese` สำหรับลงวันที่ แต่ยังไม่มีตัวละคร/event ชาวต่างชาติ; หลักฐานว่าโปรตุเกสเป็นภาษากลางเป็นของสมัยพระนารายณ์ผ่านบทความภาษาไทย (`src.jiraporn_portuguese_french_narai` ยังไม่ระบุปีและหน้า) — ควรเปิดประชุมพงศาวดาร ภาค 35–36 และจดหมายเหตุเซเบเรตตรวจ และหาหลักฐานช่วงอยุธยาตอนปลาย; ภาษามลายูของพ่อค้ามุสลิมยังเป็นการอนุมาน

## ระบบครอบครัวและการแต่งงาน — ลึกอยู่แล้ว หยุดเพิ่มก่อน
เหตุผลที่พัก: ระบบแต่งงานลึกอยู่แล้ว ส่วนที่ขาดไม่ใช่สิ่งที่ผู้เล่นบ่น · หยิบกลับมาเมื่อมี event ใหม่ที่ต้องใช้จริง

- [ ] **แต่งงานที่ยังขาด** — เมียน้อยมีแล้วแต่ผู้เล่นชายมีได้คนเดียว และ NPC ยังไม่มี; หย่าได้เมื่อเมียหมดรัก (แบ่งลูกคี่/คู่ตามลา ลูแบร์) แต่ "คืนสิน" ใช้สัดส่วนของเงินแทนเพราะเกมไม่ได้เก็บสินเดิมของเมีย และยังไม่มีเมียกลางทาษี; การบวชถูกถามก่อนแต่งงาน จึงยังไม่มีกรณีบวชระหว่างแต่งงานซึ่งตัวบทให้การสมรสสิ้นสุด; ลูกสาว/ลูกชายของผู้เล่นยังแต่งแบบย่อ (`marryOut`) ผู้เล่นยังไม่ได้เป็นฝ่ายรับขันหมาก/เรียกสินสอดเอง; สินสอดของ NPC มาจาก/ไปยังครอบครัวนอกฉาก (เงินเกิด/หายจากระบบ)

- คนไม่แต่งงานยังมีแค่ป้ายสถานะ — รายละเอียดและข้อจำกัดอยู่ใน [SYSTEM-NOTES.md](SYSTEM-NOTES.md) หัวข้อ "คนไม่แต่งงาน" (ฉากสายตาชาวบ้าน บวชชีตอนแก่ พักไว้)

- [ ] **ระบบ will/bond ยังบาง** — ความเกรง (awe) ลดได้ทางเดียวคือเลือกช่วยงาน ไม่มีการคลายลงเองตามเวลา/ตามอายุ; bond มีแค่ลูก → ผู้เลี้ยงดูผ่าน event งานครัว; นิสัยที่ต้านตัวเลือกมีแค่ boldness ใน `court_feast.chat` → ต้องใส่ `resist` ใน event ใหม่ๆ และตัดสินใจว่า bond ควรตกทอด/มีต่อคนอื่นไหม

- [ ] **ความตั้งใจยังจำกัด** — มีแค่ผู้เล่น ทีละอย่าง กับคนนอกตระกูลเท่านั้น (ญาติในแผงยังไม่มีปุ่ม); ครอบครัวของคนนอกไม่ได้จำลอง (แต่งเข้ามาแล้ว "ไปอยู่กับครอบครัวภรรยา" = ตั้งเรือนใหม่เหมือนเดิม); ทักษะที่ได้จากการไปช่วยงาน (`farming`, `trade`, `court` ฯลฯ) ยังไม่มีระบบไหนใช้; ยังไม่มีความตั้งใจแบบอื่น (ฝากตัวกับมูลนาย เรียนวิชา หาเรื่อง)

## เนื้อหา/คุณภาพที่ยังบาง (ไม่ด่วน)
- [ ] **ตำนานเกิดน้อย และความลับตำนานแตกจึงเกิดยาก** — ตำนานเกิดจากแผลเป็นที่มองเห็นของผู้นำตระกูลตอนตายเท่านั้น (ราว 0–2 เรื่องต่อเกม) event "เรื่องจริงที่ไม่มีใครเล่า" จึงเกิดราว 3 ครั้งใน 11 seed — ควรมีตำนานจากเรื่องอื่น (ตายในศึก บวชแล้วได้ดี เลื่อนยศ) ซึ่งต้องเพิ่ม claim template

## เส้นเชลยศึกและตัวละครผู้เล่นอยู่ต่างที่ (ทำเมื่อเกมมีอาชีพ/ตัวละครหลากหลายกว่านี้)
เหตุผลที่พัก: ผู้ใช้ตัดสินใจเองแล้ว (2026-11-02) — ต้องสร้างระบบใหม่ (ผู้เล่นอยู่ต่างที่ เปลี่ยนอาชีพ) ซึ่งตอนนี้เกมไม่มีที่อยู่/อาชีพนอกขุนนาง · ตอนนี้ผู้ถูกกวาดต้อนหายจากเกมเหมือนตาย (`CAPTIVE_TAG`, ดู `docs/design-war-2308.md` ขั้น 5) · หยิบกลับมาเมื่อ: เกมมีอาชีพนอกราชการและที่อยู่ของตัวละคร หรือผู้เล่นขอเส้นเรื่องนี้

- [ ] **ญาติที่ถูกกวาดต้อนไปพม่าหนีกลับมา (ย้ายจาก PLAN ข้อ 1, 2026-11-05)** — ร่างใน [design-war-2308.md](design-war-2308.md) หัวข้อ 10: lore `event.burmese_war_2308_2310` มีหลักฐานว่าเชลยบางพวกหนีกลับมาได้ (บันทึกดัตช์ 2311) แต่ไม่มีอัตรา; ค่าตั้งต้นที่เสนอ: กลับ ~15% ช่วง 2311–2316 มือเปล่า ผูกกลับ node เดิมในผังตระกูล · **พักเพราะ:** ข้อ 1 บรรลุเกณฑ์เสร็จแล้ว และการพาคนที่นับว่าตายกลับมาแตะโค้ดผังตระกูล ผู้สืบ มรดก การยุบคน เสี่ยงเซฟพัง (ผู้ใช้ตัดสิน 2026-11-05) · **หยิบกลับเมื่อ:** ทำเส้นเชลยของผู้เล่น หรือมีระบบตัวละครอยู่ต่างที่ (PLAN 4b/4c)
- [ ] **เส้นเชลยศึก: ผู้เล่นถูกกวาดต้อนไปพม่า แล้วหนีกลับ / ถูกช่วย / กลายเป็นชาวบ้านทางเหนือ (เสนอ 2026-11-02 โดยผู้ใช้)** — ถ้าตัวละครผู้เล่นถูกกวาดต้อนหลังกรุงแตก ผู้เล่นได้สัมผัสชีวิตเชลยศึก: ถ้าเก่งอาจหาทางหนีออกมาและเปิด event ผจญภัยกลับบ้าน หรือถูกคนช่วยไว้จนกลายเป็นชาวบ้านทางเหนือถาวร; ญาติ/NPC ที่ถูกกวาดต้อนอาจกลับมาได้แต่โอกาสน้อย ต้องมี event "ไปช่วย" ที่เสี่ยงให้ผู้เล่นหรือคนตายได้ ข้อควรรู้ (ความเห็นของผู้ใช้เองด้วย): ต้องสร้างระบบใหม่ — ตัวละครผู้เล่นอยู่ต่างที่ ชีวิตเปลี่ยนอาชีพ (ตอนนี้เกมไม่มีที่อยู่/ท้องถิ่นของตัวละคร ไม่มีอาชีพนอกขุนนาง) จึงควรทำหลังเกมมีอาชีพและตัวละครหลากหลายกว่านี้ เป็นงานต่อจาก `docs/design-war-2308.md` (ในขั้น 1–5 ใช้ "ถูกกวาดต้อน" = หายจากเกมไปก่อน) ข้อมูลที่ต้องค้น: ชีวิตเชลยอยุธยาในพม่า (ที่อยู่ งาน การหนีกลับ) จากแหล่งชั้นต้น
